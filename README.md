Reactive Resume is a free, open‑source resume builder and career manager. It lets users create professional resumes, download them as PDF or Word, and manage job‑search activities. The platform offers customizable templates, no ads, and supports accessibility standards (WCAG 2.1 AA). It is community‑driven, with self‑hosting options and extensive documentation.

**Areas:** OpenSource · ResumeBuilder · CareerManagement · Accessibility · Documentation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Reactive Resume: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
